# UX Modeling Service - Landing Page

## Overview
Single landing page implementation with Bootstrap 5, featuring a hero section, concise messaging, and login integration.

## Features
- Responsive Bootstrap 5 design
- Hero section with gradient background
- Prominent login button in navbar and hero
- Feature highlights
- Smooth scrolling navigation
- Login endpoint: POST /api/login
- Logout endpoint: POST /api/logout
- Session check: GET /api/session
- Protected routes
- Conditional navigation based on session state

## Quick Start

### Setup
1. Run `npm install`
2. Start the server: `npm start`
3. Open http://localhost:3000
